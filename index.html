Capabilities

三件事，做到位。

不追新技术名词，只把每一层做到真正可用：从界面、推理到系统内核。

01 / FRONT-END

前端工程

以原生 HTML / CSS / JavaScript 为底，按需引入 WebGPU、WebAssembly 与 WebRTC。没有框架依赖，也没有构建负担。

  • 原生技术栈，加载更快
  • 响应式与无障碍支持
  • 纯静态部署，随时在线
02 / AI & MODELS

AI 与模型

从零实现并训练精简语言模型，把推理搬进浏览器；同时探索本地智能体与模型训练工作台。

  • 分词器、注意力与训练全流程
  • 浏览器内实时流式推理
  • 本地 Agent 与工具调用
03 / SYSTEMS

系统与工具链

WebOS 内核、多语言终端与在线 IDE，把一整套开发环境完整地搬进网页，打开浏览器就能开始。

  • 窗口管理与应用沙箱
  • 可插拔扩展包体系
  • P2P 联机与信令交换
About NEWCYR

少一点装饰，
多一点可用。

NEWCYR 是一个独立开发者的数字作品集。每个项目都从真实需求出发，用最直接的方式解决一个问题——先能用，再好看。

长期维护、持续迭代。欢迎从任意一个作品开始，找到你需要的那一个。

01

纯前端优先

能不装就不装。打开链接就是产品，不让用户在安装页面前流失。

02

精简即完整

删掉不必要的入口与选项，让核心功能更快到达，也让维护更可持续。

03

细节决定质感

动效、排版、响应式与暗色模式，不是附加项，而是产品体验的一部分。

04

开放可扩展

扩展包、SDK 与模块化内核，把继续生长的空间留给后来者。
