# 班级管理小师 · 使用说明

> 一款面向班主任与任课老师的 Windows 桌面小工具：多张课程表按周几自动切换，到点全屏提醒并响铃，支持希沃按科目自动登录。
> 适用系统：Windows 10 / 11（64 位）。

## 1. 安装

1. 双击安装包（如 `ClassManager-Setup.exe`），若系统弹出权限提示，选择「是」。
2. 按向导操作，可自定义安装路径（默认安装到 `Program Files` 下的程序目录）。
3. 建议勾选「创建桌面快捷方式」，方便日后打开设置。
4. 完成安装后启动程序：
   - 程序**默认不弹出主窗口**，只在屏幕右下角任务栏通知区域（托盘）常驻一个小图标；
   - **首次启动会自动用浏览器打开使用说明页** <https://newcyr.github.io/class/kj.html>；
   - 安装时正在运行的其它窗口不会被抢占。
5. 如需打开设置：**双击托盘图标**，或右键托盘图标 →「打开设置」。

> 提示：若托盘图标被折叠，点击任务栏右下角的「^」小箭头即可看到。

## 2. 开机自启与后台托盘

程序以「后台常驻」方式工作：启动后自动进入托盘，非上课时间全程静默，不弹窗、不打扰。

- **开机自启**：设置页勾选「开机自动启动（后台托盘，不弹窗）」后保存。程序会写入当前用户的注册表启动项：
  `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，值名 `ClassManager`，带参数 `--tray`（仅托盘启动）。
- 取消勾选并保存，即从启动项中移除。
- 同一时间只允许运行一份程序；重复启动不会产生第二个托盘图标。

托盘菜单：

```
[托盘图标]
 ├─ 打开设置
 ├─ 立即测试全屏提醒
 ├──────────────
 └─ 退出
```

- 「打开设置」：进入课程表与希沃账号配置界面（双击图标效果相同）。
- 「立即测试全屏提醒」：立刻模拟一次上课提醒，检查铃声与全屏效果。
- 「退出」：彻底结束程序（关闭提醒、停止调度、移除托盘图标）。

> 关闭设置窗口只是把它隐藏到托盘，程序仍在后台待命。

## 3. 课程表设置

设置页打开后，顶部会显示今天的星期、使用的课程表和今日节数，以及「下一次提醒」时间，便于快速核对。

### 3.1 多张课程表

- 左侧「课程表」列表中可**新建 / 删除 / 重命名**课程表，例如「课程表A（周一至周六）」「课程表B（周日）」。
- 程序至少保留一张课程表。
- 删除某张表后，原本映射到它的星期几会自动改为使用第一张课程表。

### 3.2 周几 → 课程表映射

在「周几映射」区域，每一行是一个星期几，行末下拉框选择该天使用的课程表：

```
周一  [课程表A（周一至周六） ▼]
周二  [课程表A（周一至周六） ▼]
周三  [课程表A（周一至周六） ▼]
周四  [课程表A（周一至周六） ▼]
周五  [课程表A（周一至周六） ▼]
周六  [课程表A（周一至周六） ▼]
周日  [课程表B（周日）       ▼]
```

选择后立即生效（保存后写入配置）。

### 3.3 手动添加 / 编辑课程条目

1. 先在左侧选中要编辑的课程表。
2. 点击「添加一节课」，自动在表格末尾新增一行；新行时间会按上一节 +45 分钟自动推算。
3. 在表格中直接编辑，共四列：

| 列 | 填写说明 |
| --- | --- |
| 时间 | 24 小时制 `HH:mm`，如 `08:00`、`14:00`；**只填上课时间，没有下课时间** |
| 科目 | 从科目下拉中选择；也可先到「科目管理」新增 |
| 提前(分钟) | 本节提前多少分钟开始提醒，0–180，常用 1–2 分钟 |
| 备注 | 选填，仅作记录，不影响提醒 |

4. 选中一行后点击「删除选中条目」可移除。
5. 若想统一提前量：先设置「上课条目默认提前分钟数」，再点击「按默认分钟数填充提前量」，当前课程表全部条目会被覆盖。
6. 点击「保存设置」，提示「设置已保存，调度已生效」即完成。

> 课程条目会自动按时间升序排列，无需手动排序。

### 3.4 科目管理

- 「科目管理」中的列表是课程条目与希沃账号共用的科目来源。
- 输入新科目名后点击添加；选中后可删除。删除科目会同时删除该科目的希沃账号配置。

## 4. 闹钟与铃声

### 4.1 独立闹钟

「闹钟」表格用于非上课场景（如到校提醒、眼保健操、放学提醒），与课程表互不影响：

| 列 | 说明 |
| --- | --- |
| 时间 | `HH:mm`，24 小时制 |
| 名称 | 全屏提醒中「这节课是：」后显示的文字 |
| 启用 | 取消勾选即暂停该闹钟 |
| 提前(分钟) | 提前响铃分钟数，0–180 |

点击「添加闹钟」新增一行，选中后「删除选中闹钟」可移除。

### 4.2 自定义铃声

1. 在「闹钟铃声」区域点击「选择…」，选中本地 `.mp3` 或 `.wav` 文件。
2. 点击「试听」可试播 5 秒，确认音量与音色。
3. 点击「清空」则恢复使用**内置铃声**。
4. 保存设置后，新的铃声在下次提醒时生效。

兜底规则：若自定义文件被移动或删除，程序会自动改用内置铃声；内置音频异常时还会合成提示音，确保不会「哑火」。铃声播放约 **15 秒**，可在全屏提醒上点击任意处提前结束。

## 5. 全屏提醒的表现

到点后（已扣除提前分钟数），程序会在**所有显示器**上各显示一个全屏置顶提醒窗口，遮挡桌面内容：

```
┌──────────────────────────────────────────────────────────┐
│                      上 课 铃 声                          │
│                                                          │
│                   上课时间到了，                          │
│          请快速回到位置，做好上课准备，                    │
│                  这节课是：语文                           │
│                                                          │
│   点击屏幕任意位置关闭（3 秒倒计时） ｜ 紧急关闭：Ctrl+Alt+Shift+Q │
└──────────────────────────────────────────────────────────┘
```

- **置顶显示**：窗口始终在最前，`Alt+F4` 与系统关闭按钮被屏蔽，避免被学生误关。
- **多显示器**：每块屏幕都会出现遮罩；高 DPI 缩放下也能铺满整屏。
- **铃声**：最长播放 15 秒，循环播放自定义铃声；点击屏幕后立即停止。
- **点击关闭**：点击任意位置后开始 **3 秒倒计时**，倒计时结束自动关闭全部遮罩。
- **紧急关闭**：在任何时候按下 `Ctrl + Alt + Shift + Q`，可立即关闭所有屏幕的提醒并停止铃声（无需先用鼠标点击）。
- 关闭提醒后程序自动回到托盘待命，等待下一次触发。

> 设置页的「测试全屏提醒」与托盘菜单的「立即测试全屏提醒」可用于课前检查。

## 6. 希沃自动登录

程序可按「当堂科目」自动登录希沃白板，省去每节课手动切换账号。该功能全程**静默执行**，即使失败也不弹窗、不影响全屏提醒。

### 6.1 配置账号

1. 打开设置页 →「希沃账号（按科目）」表格。
2. 每一行对应一个科目：填写该科目的**希沃账号**与**密码**。
3. 勾选「闹钟触发后自动执行希沃登录（按当堂科目）」。
4. 点击「保存设置」。密码保存到本地时会自动用 Windows DPAPI 加密（密文以 `dpapi:` 开头），不会以明文落盘。

> 科目文字需与课程条目中的科目**完全一致**，程序才会在对应课程提醒时匹配账号。

### 6.2 执行流程（自动）

```
上课提醒触发
   ↓
按当堂科目查找已填密码的账号
   ↓
定位希沃客户端（已在运行则直接复用，未运行则启动）
   ↓
检测登录状态 → 已登录则先退出上一账号
   ↓
填写账号密码 → 提交登录 → 校验登录结果
   ↓（任何一步失败）
仅写日志，静默结束
```

- 若当堂科目未配置账号或密码，则跳过自动登录，仅记录一条日志。
- 独立闹钟（非课程条目）不会触发希沃登录。

### 6.3 自检与日志

- 设置页「希沃登录自检（后台执行，不弹窗）」会选取第一个已填写账号的科目，在后台执行一次登录，不抢占前台。
- 详细过程与结果写入日志：
  `%APPDATA%\ClassManager\logs\seewo.log`
- 日志会记录：是否找到希沃程序、是否需要退出旧账号、填表是否成功、登录结果是否确认等。

## 7. JSON 导入 / 导出

适合批量生成课程表、备份到其它电脑或在多台设备间同步。

- **入口**：设置页底部 →「导入 JSON…」/「导出 JSON…」。
- **导入**：选择 `.json` 文件后整体替换当前配置，并立即保存、重新计算提醒；若文件有误会提示具体原因，原配置保持不变。
- **导出**：生成 `classmanager-课程表.json`，**默认不包含密码明文**（其它电脑需重新填写希沃密码）。
- 手动在设置页填写的内容与 JSON 字段一一对应，可放心混用。

完整的字段说明、示例与常见错误，请参阅 **[课程表 JSON 格式 SDK 文档](sdk.md)**（`docs/sdk.md`）。

## 8. 常见问题 FAQ

**Q1：到了时间却没有提醒？**

请依次检查：

1. 程序是否在运行（托盘是否有图标）；若已退出，需重新启动。
2. 设置页顶部「今天使用：XXX（N 节）」是否为期望的课程表——周几映射是否选对。
3. 课程条目时间是否为 24 小时制 `HH:mm`，是否误填成 `8:00` 等格式。
4. 是否设置了「提前 N 分钟」导致提醒时间提前；例如 08:00 的课、提前 2 分钟，会在 07:58 响。
5. 电脑是否处于睡眠 / 休眠；唤醒后错过的提醒不会补发。
6. 点击「保存设置」确认配置已生效（未保存的修改不会参与调度）。

**Q2：全屏提醒出现但没有声音？**

1. 检查系统音量、是否静音，以及输出设备是否正确。
2. 若使用自定义 mp3，确认文件仍在原路径；文件被移动/删除会自动回退到内置铃声。
3. 用「试听」按钮验证铃声文件是否能正常播放。
4. 部分 mp3 编码不被支持时可能无声，建议转为常见码率或改用 `.wav`。
5. 查看 `%APPDATA%\ClassManager\logs\ring.log` 是否有播放失败记录。

**Q3：希沃没有自动登录 / 提示未找到希沃？**

1. 确认本机已安装希沃白板客户端，且能手动正常启动。
2. 检查该科目是否填写了账号和密码，科目名称是否与课程条目完全一致（注意多余空格）。
3. 确认「闹钟触发后自动执行希沃登录」已勾选并保存。
4. 打开 `%APPDATA%\ClassManager\logs\seewo.log`，查看失败原因（未找到程序、等待窗口超时、填表失败等）。
5. 希沃客户端升级后界面元素可能变化，导致自动填表失败；此时仍可手动登录，不影响上课提醒本身。

**Q4：如何彻底退出程序？**

- 右键托盘图标 →「退出」。
- 仅关闭设置窗口不会退出，程序仍会在后台提醒。
- 若托盘图标异常消失，可在任务管理器中结束 `ClassManager` 进程。

**Q5：换电脑后希沃密码没了？**

密码使用 Windows DPAPI 与当前用户绑定加密，复制配置或导出 JSON 都不会带出可用密码。请在新电脑的设置页重新填写一次。

**Q6：修改了 JSON 但程序没变化？**

需通过设置页「导入 JSON…」导入后才会生效；直接修改 `config.json` 时请先退出程序，否则程序保存时可能覆盖你的修改。

## 9. 数据目录与日志

所有数据均保存在当前用户目录下：

```
%APPDATA%\ClassManager\
 ├─ config.json          课程表与全部设置（密码为 DPAPI 密文）
 ├─ state.json           程序内部状态（如是否已打开过说明页）
 └─ logs\
     ├─ app.log          启动、异常等
     ├─ config.log       配置读取失败等
     ├─ seewo.log        希沃自动登录过程
     ├─ ring.log         铃声播放异常
     └─ autostart.log    开机自启写入异常
```

- 在设置页点击「打开数据目录」可直接定位到该文件夹。
- 备份：复制 `config.json` 或使用「导出 JSON…」即可。
- 重置：退出程序后删除 `config.json`，再次启动会生成默认配置。
