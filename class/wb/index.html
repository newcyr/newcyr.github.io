导入方法

  1. 点击上方任一“下载”，保存 wb.json。
  2. 打开「班级管理小师」→ 设置 → 导入 JSON。
  3. 选择刚下载的 wb.json，确认导入后课程表与周映射即生效。
  4. 之后在“课程表”页逐节填写科目即可，时间与提前分钟数无需再改。

导入会覆盖当前课程表、周映射与闹钟配置，请先导出备份。
