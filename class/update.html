更新通知v1.2.0

发布时间：2026-11-20 · 适用于 Windows 10 / 11 x64

本次更新内容

  • 手动检查更新：设置页新增“立即检查更新”；只有点击后才会访问 gx.json、下载安装包并静默安装，程序不会再自动检查或自动更新。
  • 修复希沃账号填写区消失：导入课表 JSON 不再覆盖本机已填写的希沃账号；科目列表会自动补齐对应的账号输入行。
  • 希沃退出 / 登录增强：按本机希沃白板真实界面适配——自动展开右上角账号菜单、识别“退出登录”、跨窗口处理确认弹窗，并等待登录面板出现后再填写账号；登录前自动勾选用户隐私协议。
  • 课程表拆分：星期一至星期日各一张独立课表，方便单独调整某一天；全部课时提前 2 分钟 提醒。
  • 安装方式调整：改为安装到当前用户目录（%LOCALAPPDATA%\Programs\ClassManager），无需管理员权限，才能实现真正的静默更新。
  • 保留：全屏置顶提醒、15 秒自动关闭、点击关闭、紧急热键、自定义铃声、开机自启、非上课静默。

获取新版本

在设置页点击“立即检查更新”即可；也可以直接下载覆盖安装（个人配置与账号会保留）。

打开下载页 课程表 JSON

如果你之前安装在 C:\Program Files\ClassManager，新版本会安装在当前用户目录，建议在“应用和功能”里卸载旧版本，避免两份程序共存。

升级后检查

  • 设置页确认“开机自动启动”已勾选。
  • 重新填写/确认各科希沃账号与密码（旧账号数据不会再被课表导入清空）。
  • 导入新的 wb.json 后，周一到周日会显示为 7 张独立课表。
