它做什么

为教室场景做的取舍：只在上课前提醒，其余时间绝不打扰。

铃

提前响铃

每节课按设置提前几分钟响铃，默认 3 分钟，铃声约 15 秒。

屏

全屏提醒

到点全屏置顶遮罩，显示科目与提示语，点击提前关闭，15 秒后自动关闭。

课

多课程表

周一至周日可映射不同课程表，手动填写与 JSON 导入字段一致。

希

希沃自动登录

按当堂科目切换希沃账号，密码 DPAPI 加密保存，失败静默。

启

开机自启

写入当前用户启动项，静默驻留托盘，不弹窗打扰。

静

非上课静默

没有课程的时间里不响铃、不弹窗、不抢占屏幕。
