功能特性

该响的时候，屏幕替你喊人

从课程表到铃声再到希沃登录，所有功能都围绕一件事：让下一节课准时开始。

多课程表 · 周几映射

可建立多套课程表，周一至周日分别映射到不同表，工作日与周末课表互不干扰。

提前 N 分钟全屏提醒

每节课可单独设置提前分钟数，到点在所有显示器上全屏弹出，置顶显示且屏蔽 Alt+F4。

约 15 秒铃声

提醒响起时播放约 15 秒铃声，循环播放所选音频；点击屏幕后进入 3 秒倒计时自动关闭。

自定义 MP3 铃声

支持选择本机 MP3 / WAV 作为铃声，文件被移动或删除时自动回退到内置提示音。

按科目希沃自动登录

为不同科目保存对应账号，提醒触发后自动打开希沃并登录；密码用 Windows DPAPI 加密存储。

开机自启 · 托盘常驻

随系统启动静默驻留托盘，双击图标即可打开设置；独立闹钟可补充到校、下课等时间点。

安装前请确认

  • 校验安装包：可在 GitHub Release 页面核对文件大小与 SHA256；或在 PowerShell 执行 Get-FileHash .\ClassManagerSetup.exe -Algorithm SHA256 后比对。也可右键安装包 →「属性」→「数字签名」查看签名者。
  • 管理员权限：安装与首次运行需要管理员权限（用于写入程序目录及注册开机自启项）。
  • 系统要求：仅支持 Windows 10 / 11 x64，暂不提供 32 位与 ARM 版本。

使用说明

六步完成配置，之后交给托盘

第一次使用只需配置一次课程表与账号，之后程序会在后台按周几自动工作。

  1. 01

    下载安装包

    任选上方一条下载线路，得到 ClassManagerSetup.exe。

  2. 02

    运行安装

    右键「以管理员身份运行」，按提示完成安装；首次启动会自动打开本页使用说明。

  3. 03

    设置课程表

    双击托盘图标打开设置，添加上课时间与科目，可建立多套课程表。

  4. 04

    配置周几映射

    把周一至周日分别指定到对应课程表，例如周一至周六用 A 表、周日用 B 表。

  5. 05

    填写希沃账号

    在账号列表按科目填写账号与密码，保存后自动以 DPAPI 加密，仅本机可解密。

  6. 06

    保存并测试

    点击「保存」，用托盘菜单的「立即测试全屏提醒」预览效果，建议同时开启开机自启。

全屏提醒的实际行为
  • 按每节课设置的提前分钟数触发，0 表示准点提醒
  • 覆盖所有显示器并置顶显示，屏蔽 Alt+F4 误关
  • 铃声约 15 秒，可循环播放自定义 MP3 / WAV
  • 点击屏幕任意位置，3 秒倒计时后自动关闭
  • 紧急关闭快捷键：Ctrl + Alt + Shift + Q
  • 课程提醒可同时按科目自动登录希沃（可选）

课程表 JSON

懂 JSON？直接改文件也行

设置界面与 JSON 字段一一对应，支持导入 / 导出，方便批量排课与多机同步。

字段说明与完整示例 点击展开，查看课程表 JSON 结构与可直接导入的示例 +

完整文档见 sdk.md。本地配置文件路径为 %APPDATA%\ClassManager\config.json；导入时 schemaVersion 必须为 1， 时间使用 24 小时制 HH:mm。

字段类型说明
schemaVersionnumber结构版本，当前固定为 1
subjectsstring[]科目列表；课程条目中的新科目会自动补入
defaultAdvanceMinutesnumber默认提前分钟数（0–180）
ringtonePathstring自定义铃声绝对路径，支持 .mp3 / .wav；留空使用内置铃声
timetablesTimetable[]多套课程表
timetables[].idstring课程表唯一 id，供 weekMapping 引用
timetables[].namestring课程表名称
timetables[].entriesCourseEntry[]上课条目，保存时按时间升序排列
entries[].timestring上课时间，24 小时制 HH:mm
entries[].subjectstring科目名称，对应 subjects 中的一项
entries[].advanceMinutesnumber该节课提前分钟数（0–180），0 表示准点
entries[].notestring备注，可为空字符串
weekMappingstring[7]周一至周日各自对应的课程表 id，固定 7 项
alarmsAlarmItem[]独立闹钟（不依赖课程表）
alarms[].idstring闹钟唯一 id
alarms[].timestring闹钟时间，24 小时制 HH:mm
alarms[].labelstring闹钟文字，全屏提醒中会直接显示
alarms[].enabledboolean是否启用该闹钟
alarms[].advanceMinutesnumber提前分钟数（0–180）
seewoAccountsSeewoAccount[]按科目保存的希沃账号
seewoAccounts[].subjectstring科目名称
seewoAccounts[].accountstring希沃账号
seewoAccounts[].passwordstring仅内存中为明文；落盘为 DPAPI 密文（dpapi: 前缀）
seewoLoginEnabledboolean上课提醒触发后自动登录希沃
startWithWindowsboolean开机自启（写入 HKCU Run）

FAQ

        
常见问题

        
没响铃、没声音、希沃不登录？先看这里，大部分情况都能自行排查。

      


      

        

          到点没有响铃怎么办？
          

            
依次检查：①当天是否被「周几映射」指向了正确的课程表；②修改课程表后是否点击「保存」；③托盘图标是否仍在（程序是否被退出）；④电脑是否处于休眠或关机状态；⑤系统时间与时区是否正确；⑥该节课的「提前分钟数」是否设置过大或为 0。

            
可用托盘菜单「立即测试全屏提醒」快速验证提醒与铃声链路。

          

        


        

          有提醒但铃声没声音？
          

            
请确认系统音量、输出设备与静音状态。自定义铃声若被移动或删除，程序会自动回退到内置提示音；个别编码的 MP3 可能无法播放，可转为标准 MP3 或 16-bit WAV 后再试。远程桌面或无声卡环境下也可能没有声音输出。

          

        


        

          电脑没装希沃，会自动登录吗？
          

            
不会。程序会从注册表与常见安装目录查找希沃客户端，未安装时自动跳过登录，不影响上课提醒，也不会弹出错误窗口。需要安装希沃白板 5 或对应希沃客户端后才能启用该功能。

          

        


        

          希沃密码安全吗？会不会明文保存？
          

            
密码使用 Windows DPAPI 按当前用户加密，以 dpapi: 密文写入 %APPDATA%\ClassManager\config.json，换电脑或换系统用户都无法解密；全程不联网上传。导出课程表 JSON 时默认不包含密码明文。

          

        


        

          能不能设置下课提醒？
          

            
课程条目只记录上课时间，不设下课时间。可以在「独立闹钟」中新增一条，例如 08:40、标签写「下课」，它同样会触发全屏提醒，只是显示的文字为闹钟标签。

          

        


        

          全屏提醒怎么关？如何彻底退出程序？
          

            
全屏提醒出现后，点击屏幕任意位置即可开始 3 秒倒计时关闭；也可以按 Ctrl + Alt + Shift + Q 紧急关闭。要彻底退出，请在任务栏托盘右键图标选择「退出」，程序会停止调度；若不想再开机自启，在设置中关闭「开机自启」。

          

        


        

          多显示器或希沃一体机会怎样显示？
          

            
提醒会在每块显示器上分别全屏覆盖，避免学生从副屏看到桌面；高 DPI 下按物理像素铺满，不会出现黑边或缩放错位。希沃一体机的内置屏幕同样适用。
