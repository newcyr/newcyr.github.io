# newcyr.github.io · NEWCYR 官方站点

独立开发者数字作品官网。访问 <https://newcyr.github.io/> 即可打开。

## 特性

- **纯白亮色**为默认视觉，可一键切换至暗色主题，偏好自动保存在本地。
- **中英文切换**：导航、正文、页脚与项目卡片均可双语显示。
- **单文件实现**：全部内容集中在根目录 `index.html`，无构建流程、无外部依赖。
- **六个核心项目**：MiniLLM、WebNT、PolyTerm、Python IDE、Lumina、Gomoku，点击直达。
- **响应式**：适配桌面、平板与手机，支持无障碍焦点与减弱动效偏好。
