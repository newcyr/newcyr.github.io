核心能力

从一句目标，到一份能执行的清单

TodoX 把 LLM 的计划能力和 Microsoft To Do 的任务字段连在一起：生成、检查、筛选、同步，都在一个应用里完成。

一句话生成计划

描述目标，LLM 自动拆成 5–12 个可执行任务，并按天或按阶段安排截止日期。

原生 To Do 字段

任务标题、备注、截止日期、重要程度、子检查项，一一对应 Microsoft To Do。

一键同步

登录 Microsoft 账户后，一次点击创建新清单，逐条写入任务与子项，无需复制粘贴。

同步前可筛选

生成结果先预览，取消勾选不需要的任务，只把真正要做的写进 To Do。

两种网页登录

设备代码流与授权码 PKCE 两种方式，登录页在应用内浏览器打开，不再跳转系统浏览器。

可关闭深度思考

针对 DeepSeek 与智谱 GLM，可选发送 thinking.type = disabled，减少等待时间与 token 消耗。

本地优先

API Key 与登录令牌仅保存在应用私有目录，没有中转服务器、统计或广告 SDK。

三步完成

配置一次，之后只需一句话

不需要搭建服务器，也不需要复制任务。应用直接与你的 LLM 服务和 Microsoft Graph 通信。

同步机制

走微软官方 Microsoft Graph 接口

Microsoft To Do 没有独立的公开 API。TodoX 使用 Microsoft Graph v1.0 的 /me/todo 接口读写清单，两种网页授权均在应用内浏览器完成。

  • 使用委托权限 Tasks.ReadWrite，只访问当前账户的 To Do 数据。
  • 默认使用内置的微软公共客户端；也可在设置中填入自建 Azure 应用的 Client ID。
  • 写入标题、备注、截止时间、重要程度与检查项，保留计划结构。
  • 应用没有后端中转：计划内容只发送给你配置的 LLM 与 Microsoft Graph。

安装与使用

四步开始你的第一份 AI 计划

TodoX 不需要注册 NEWCYR 账户。你只需要一个 LLM API Key 和一个 Microsoft 账户。

01

下载 APK

点击下载按钮，得到 todox-1.0.2.apk。建议通过手机浏览器直接下载安装。

02

允许安装

Android 会提示“未知来源应用”。在系统设置中允许浏览器或文件管理器安装应用。

03

配置 LLM

打开 TodoX → 右上角设置 → 填写 Base URL、API Key、模型 → 点击“测试连接”。

04

生成并同步

输入目标 → 生成计划 → 一键同步 → 浏览器输入设备码完成授权，任务自动写入 To Do。

提示：卸载应用会同时清除本机保存的 API Key 与 Microsoft 登录令牌，但不会删除已经同步到 Microsoft To Do 的任务。生成的计划内容请在同步前自行检查。
FAQ

常见问题

关于 LLM 配置、Microsoft 登录与同步的常见疑问。

使用 TodoX 需要准备什么？+

一个兼容 OpenAI Chat Completions 的 LLM API Key（例如 OpenAI、DeepSeek、Moonshot、SiliconFlow 或自建 One API），以及一个可登录 Microsoft To Do 的 Microsoft 账户。应用本身不需要 NEWCYR 账户，也不需要服务器。

支持哪些大模型服务？+

任何提供 /chat/completions 接口并支持 Bearer API Key 的服务都可以。设置里内置了 OpenAI、DeepSeek 与智谱 GLM 预设，其余服务选择“自定义”并填写 Base URL 与模型名称即可。Base URL 应包含版本路径，例如 https://api.openai.com/v1。

我的计划与 API Key 会被上传到 NEWCYR 吗？+

不会。应用直接请求你配置的 LLM 服务与 Microsoft Graph。NEWCYR 没有中转服务器，页面与应用均不包含统计、广告或第三方追踪 SDK。API Key 与登录令牌保存在 Android 应用私有目录。

同步失败怎么办？+

先检查设置中的 Microsoft 账户状态：令牌可能过期，断开后重新连接即可。其次确认网络可以访问 graph.microsoft.com。403 通常表示授权未完成或权限被组织策略阻止；429 表示请求频率过高，稍后重试即可。

每次同步会不会重复创建清单？+

每次同步都会在 Microsoft To Do 中创建一个名为“TodoX · 计划名称”的新清单，方便整份计划独立管理。如果重复点击同步，会生成多份清单，请在同步前确认。

如何关闭 DeepSeek / GLM 的思考模式？+

在设置页打开“关闭 DeepSeek / GLM 思考模式”开关即可，默认开启。应用会在请求中发送 thinking.type = disabled。强制思考的模型（如部分 GLM-5.3 系列）不受此开关影响。

两种 Microsoft 登录方式有什么区别？+

方案一设备代码：应用内显示一次性代码，在应用内浏览器登录，授权后自动完成，推荐大多数用户使用。方案二授权码 PKCE：适合自建 Azure 应用，在应用内浏览器登录后自动截获回调链接并换取令牌，也可手动粘贴；需自行注册与回调地址一致的 Redirect URI。

登录时会跳转到系统浏览器吗？+

不会。登录页在应用内浏览器打开（基于系统 WebView，与 Via 同一内核），避免跳转外部浏览器时应用被系统回收而出现“重启”。如果应用内页面加载失败，可点击右上角图标切换到系统浏览器。

个人 Microsoft 账户可以使用吗？+

可以。两种登录方式都支持个人账户与工作/学校账户。若所在组织的策略阻止登录，可在设置中填入自建 Azure 应用的 Client ID：应用需配置为公共客户端、启用设备代码流或注册回调地址，并添加委托权限 Tasks.ReadWrite。
